# 产品与验收说明

## 产品目标

用户不需要知道启动项位于哪个目录或使用哪条命令。LaunchScope 以“所属应用/自定义命令”为中心归组，同时保留底层证据，支持从概览逐层展开到原始配置。

## 状态模型

界面分别显示以下状态，不能压缩为单个开关：

1. 配置是否存在；
2. 配置是否标记启用；
3. launchd 是否加载；
4. 进程是否正在运行；
5. 执行目标是否仍然存在。

## 首版验收场景

- 首次打开自动扫描，扫描期间窗口可以交互且显示进度。
- 默认进入“第三方与自定义”，Apple 系统项不干扰主要列表。
- 关闭“隐藏 Apple 项目”并进入“全部项目”后可查看系统项。
- 点击项目后可查看来源路径、执行文件、参数、启动条件、签名和原始 plist 字段。
- `KeepAlive` 字典、日历计划、环境变量等复杂值不会导致解析崩溃。
- 执行文件已删除时显示“目标已缺失”。
- BTM、Homebrew 或 crontab 不可用时其他来源仍正常展示，并在“扫描提示”解释原因。
- 搜索可以匹配应用名、Label、Bundle ID、Team ID、路径和参数。
- 敏感环境变量默认显示为圆点，用户明确开启后才显示原值。
- 详情页按来源显示处置建议；登录项可跳转系统设置，文件型来源可在 Finder 中定位。
- 只读诊断命令会正确转义动态参数，复制命令不会自动执行。

## 后续候选

- 可恢复停用、配置备份与回滚
- 资源占用与启动耗时观察

## 第二阶段：可恢复控制

- 仅允许操作当前用户 `~/Library/LaunchAgents` 目录中的非 Apple 项目。
- 停用执行 launchd `disable` 与 `bootout`，恢复执行 `enable` 与 `bootstrap`。
- 不删除、移动或改写原始 plist；每次操作前二次确认，操作后自动重新扫描。
- `print-disabled` 的 override 状态与 Loaded、Running 分开显示，不能因停用而掩盖仍在运行的进程。
- 该阶段暂不直接操作全局 Agent、Daemon、系统项目、Homebrew、Cron、Shell 与后台任务。

## 第三阶段：Homebrew 服务控制

- 只操作无 `sudo` 的当前用户 Homebrew 服务，不管理 root LaunchDaemon。
- 运行中的服务可执行 `brew services stop`，停止并取消登录启动；停止状态可执行 `brew services start` 恢复。
- 服务名必须来自扫描结果并通过保守格式校验；命令使用参数数组执行，不经过 shell。
- 操作前二次确认，命令设置 15 秒超时并捕获 stderr，操作后自动重新扫描。

## 第四阶段：操作历史与撤销

- 在 Application Support 中最多保存 100 条 JSON 历史，写入使用原子替换。
- 历史只包含稳定项目标识、显示名、来源、动作、前后状态、结果和时间；不得保存路径、参数、环境变量或原始配置。
- 仅允许撤销该项目最新、成功且未撤销的操作，并要求当前扫描状态对应的可用动作与反向动作一致。
- 撤销仍需经过原控制器的目录、UID、来源、服务名与权限边界校验，完成后重新扫描并生成新的历史记录。
- 历史读取或保存失败必须在界面提示，不能静默丢失。

## 第五阶段：扫描差异

- 每次完成扫描后，以 SHA-256 处理后的稳定项目 ID 保存一份脱敏快照，并与上一次完成扫描比较。
- 快照只保留 label、安全显示名、来源、允许状态、运行状态、目标存在性、签名类型和 Apple 归属。
- 不保存路径、参数、环境变量、Cron 命令或原始配置；首次扫描只建立基线。
- 变化分为新增、移除与状态变化；状态变化明确列出名称、允许、运行、目标、签名或 Apple 归属字段。
- 快照读取或保存失败必须在扫描变化界面提示，写入使用原子替换。

## 第六阶段：报告、信任与提醒

- JSON 可包含项目、脱敏问题摘要与最近变化；CSV 提供项目表。导出前必须展示字段预览并可选择当前筛选或全部项目。
- 默认排除路径、参数、环境变量、原始配置、PID、证书链与用户备注；只有用户明确勾选时 JSON 才包含备注。
- 备注、标签和信任状态以来源与标识组成的脱敏稳定键持久化，不保存启动路径和配置内容。
- 提供未信任筛选与隐藏已信任项目选项；相邻扫描中新出现且未信任的第三方项目需要明显标记。
- 系统通知默认关闭，用户主动开启时才请求权限；相同扫描变化使用持久化脱敏键去重，避免重复提醒。
